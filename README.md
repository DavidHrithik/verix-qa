# Verix — Unified AI QA Workspace

Verix is a modular enterprise software testing platform foundation designed for modern QA teams and SDETs.

## Features
- **Polished Application Shell**: Collapsible left sidebar, responsive mobile drawer, top navigation with dynamic project selector, sprint indicator, and notifications.
- **Design System & AI UI**: Light and Dark mode tokens, comprehensive UI components (Buttons, Inputs, Multi-selects, Tables, Modals, Drawers, SplitPanes, Badges, ProgressBars), and specialized AI components (`AIActionButton`, `AIGeneratedBadge`, `AIConfidenceIndicator`, `AIApproveReject`, `AILoadingState`).
- **Command Palette (`Cmd+K`)**: Instant search and navigation across all modules and actions.
- **Isolated Team Modules**: Zero-coupling architecture for parallel development across Coverage Bridge, AI Test Case Generation, Step Expansion, Self-Healing Automation, Task Allocation, and Test Repository.
- **Centralized Mock Data Layer**: Typed mock fixtures for projects, stories, test cases, tasks, coverage, and executions.

## Getting Started

```bash
npm install
npm run dev
```
